Kenali resource dan scope

YouTube Data API menggunakan resource video dengan snippet, status, dan detail processing. Untuk upload, aplikasi memakai OAuth scope seperti youtube.upload. API key saja tidak cukup untuk menulis ke channel pengguna.

Kelola Konten menampilkan channel yang diotorisasi, expiry, scope, dan verification state. Pengguna dapat disconnect tanpa menempelkan credential manual. Token disimpan terenkripsi dan tidak pernah dimasukkan ke analytics event.

Buat project Google Cloud khusus aplikasi. Simpan client ID dan secret di environment operator. Redirect URI harus cocok persis dengan konfigurasi sehingga kegagalan OAuth dapat dibedakan dari penolakan permission.

Buat video dengan metadata yang valid

Draft mencatat title, description, tags, category, privacyStatus, file, dan waktu publish. Field wajib divalidasi sebelum upload. Preview membantu menemukan judul kosong, karakter bermasalah, atau media yang terlalu besar.

Gunakan resumable upload agar koneksi yang terputus tidak mengulang seluruh file. Simpan upload session dan status chunk secara aman. Jika sesi kedaluwarsa, buat retry yang tidak membuat kartu kalender menjadi ganda.

Metadata harus berasal dari brief yang disetujui. Jangan menambahkan klaim atau link otomatis tanpa review. Simpan versi caption supaya perubahan setelah approved terlihat.

Pahami private-until-audit

Referensi videos.insert menyatakan video dari unverified API project yang dibuat setelah 28 Juli 2020 dibatasi private sampai project diaudit. Copy produk harus menampilkan batasan ini sebagai status, bukan catatan tersembunyi.

Private upload tetap berguna untuk review internal, penjadwalan di YouTube Studio, atau pemeriksaan processing. Bedakan private, unlisted, dan public pada selector, lalu kunci pilihan yang tidak diizinkan provider.

Jangan menjadikan HTTP 200 sebagai bukti tayang. Simpan video ID, panggil videos.list dengan processingDetails, lalu baca status. URL publik hanya dapat disebut setelah visibility dan processing benar-benar terverifikasi.

Pantau processing dan quota

Processing dapat berlangsung setelah videos.insert sukses. Queue menyimpan pending, succeeded, atau failed, dengan retry terbatas. Error detail ditampilkan kepada pemilik tanpa membocorkan token atau response mentah yang sensitif.

YouTube memakai quota. Dokumentasi menyebut default allocation dan bucket upload yang dapat berubah. Kelola Konten menampilkan quota error dan link sumber, tetapi tidak menjanjikan jumlah upload tetap di halaman pemasaran.

Buat health view untuk upload queue, waktu terakhir sukses, dan error terbaru. Operator dapat mengambil tindakan sebelum pengguna membuat banyak retry.

Kolaborasi dan approval

Reviewer memeriksa title, thumbnail, description, privacy, dan link. Comment internal menempel pada draft. Jika file atau privacy berubah, status kembali review.

Agensi dapat menyimpan channel per workspace. Pengguna yang hanya reviewer tidak boleh mengganti OAuth atau menghapus video. Uji isolasi dua organisasi sebelum beta.

Laporan performa tidak boleh mengarang views saat data belum tersedia. Tampilkan processing atau no data dan timestamp pengambilan.

Rencanakan peluncuran

Mulai dengan private test upload dan catat seluruh status. Ajukan audit jika use case dan compliance siap. Setelah audit, jalankan test publik dengan konten yang disetujui.

Artikel, status page, dan UI memakai bahasa yang sama: upload berhasil, processing berjalan, private-only, public verified, atau failed. Keseragaman istilah mengurangi permintaan dukungan.

Gunakan hasil test untuk memutuskan apakah video otomatis masuk beta. Jika audit belum selesai, tetap sediakan draft dan handoff, lalu labeli fase tersebut `bergantung persetujuan platform`.

Pertanyaan yang sering muncul

Mengapa video tetap private?

Project API yang belum diverifikasi dapat membatasi video ke private. Ikuti status audit dan dokumen YouTube sebelum menyebut video publik.

Apakah API key dapat upload?

Upload memerlukan OAuth scope yang sesuai, seperti youtube.upload. API key saja tidak memberi otorisasi channel.

Bagaimana memastikan upload selesai?

Simpan video ID, panggil videos.list untuk processingDetails, dan periksa status visibility setelah processing.

Apakah quota selalu 10.000 unit?

Default quota dapat berubah dan upload memiliki aturan bucket. Link ke quota docs dan tampilkan error aktual.
